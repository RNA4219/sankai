# sankai

sankaiは既存スキルを**分解・理解・溶解**し、必要な仕事を担う指示本文を取り出すスキルである。取り出した指示に適用条件・依存先・例外・出典を付け、単独で使える範囲と、一緒に必要なものを示す。手順書やプロンプトも対象にする。

## 使い方

`skills/sankai/`を、利用するAIエージェントのスキル配置先へコピーする。スキルを直接参照させる場合は、[SKILL.md](skills/sankai/SKILL.md)を入口にする。

対象のスキルと取り出したい仕事を渡して、次のように依頼する。

> このスキルをsankaiして。検索する部分だけ別の作業で使いたいので、必要な指示を、条件・依存先・例外ごと取り出して。

用途が未指定なら、仕事の切れ目から候補を分ける。本文だけ、Markdownなど出力形式の指定があれば、その形式を優先する。

## 分解・理解・溶解で返すもの

| 働き | 返すもの |
|---|---|
| 分解 | 仕事ごとの指示本文と、使う場面・条件・依存先・例外・出典 |
| 理解 | その単位で取り出せる理由、指示が達成・維持すること、利用に影響する不明点 |
| 溶解 | 元の配置や具体例から取り出した指示本文と、維持する条件・変えられる範囲 |

役割の一覧や解説だけで終えず、指示本文を成果物にする。ファイルや見出しの境目と、仕事の境目は区別する。別の節にある共通条件や例外も残し、依存資料が足りない部分を完成した独立スキルとは扱わない。

結果は一つの文書にまとめられる。900字前後以上の入力では、別指定がなければ出力全体を入力の1.3倍以内にする目安がある。必要な条件を別紙へ逃がさず、HTMLの引用や折りたたみ内も数える。

## このリポジトリの内容

- [sankai本体](skills/sankai/SKILL.md)：使う場面と、3つの働きの手順。
- [説明HTML](index.html)：取り出した指示本文と、引用・原文への導線。リポジトリを取得し、ブラウザーで開いて読める。
- [RustXNGから取り出した例](examples/rustxng-search.md)：検索にも必要な接続確認を残し、導入・起動などを外した例。
- [例に使った元スキル](examples/rustxng-source.md)：個人のローカルパスを一般表記へ置き換えた資料。

## 確認できている範囲

RustXNG向けスキルで指示を取り出す試用を行い、原文と照合した。初回に抜けた外部送信の説明は、照合手順を補った後の再試用で保持された。掲載する結果はさらに依存条件などを原文に合わせて整えている。

試用は一つの題材に限られる。例に書かれた検索やサービス操作は実行しておらず、依存するガイドや監査資料もこのリポジトリには同梱していない。

sankaiの機能は分解・理解・溶解の3つである。指示の実行・登録、別の仕事への組み直し、専用の自動分解機構は含まない。
